# Meltypeインストール&設定

## インストール

- Karabiner-Elements
  - https://karabiner-elements.pqrs.org/
  - 入力監視の許可が必要
- GooleIME
  - https://www.google.co.jp/ime/
- Meltype
  - https://github.com/yksr-melt/Meltype/blob/main/mac/README.md
  - ダウンロード後にインストールコマンド実行
```bash
~/Downloads/Meltype-mac/Install\ Meltype.command
```

## Karabiner-Elements経由でショートカットを設定

```bash
curl -fsSL https://raw.githubusercontent.com/tkc310/settings/refs/heads/main/meltype/meltype-karabiner.sh | bash
```
